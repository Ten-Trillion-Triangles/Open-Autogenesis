## Notes

- I found no `skipReasoning()` usage anywhere in Autogenesis, so the new TPipe flag is not being set explicitly in this repository.
- The `AgentWorkStreamManager` visibility drop path is old and therefore unlikely to be the branch-specific regression, but it is still a real chunk-loss point worth keeping in mind.
- The recursive `pipe.reasoningPipe` wiring in `AgentWorkStreamStreaming.kt` is still present, so the server side still intends to stream reasoning children.
