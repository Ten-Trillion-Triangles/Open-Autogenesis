##What you must do##

**Step 1**

The user will request you help plan the creation of or the modification of a KVision widget. You must:

- Discuss and take in all requirements
- Ask about desired style and take in that information
- Generate mock up images to show what it might look like
- Iterate with the user until they have marked this as complete

**Step 2**

- Research the codebase and determine what successful widgets look codewise.
- Use web search to completely document and research KVision
- Prove with grounding that you are not hallcuinating
- Validate you not cowboy coding doing raw dom writes, css hacks,
hmtl hacks, or any other action you couldn't do through KVision correctly in the first place

**Step 3**
Generate a steering document to guide and sure you follow the rules of KVision, don't cowboy code, know what you need to have in order to correctly implement, and keep the requirements at hand at all times

**Step 4**
Generate a plan the user can iterate on and review. Require keeping the steering data into context, the requirements into context, invoking the ui-builder workflow to implement the plan.
